# E40002 Environment\_Error\_Incorrect\_Python\_Version

## 错误信息

报错格式如下，占位符%s都表示版本号：

```text
Unsupported Python version: %s. Expected: %s or later.
```

报错示例如下：

```text
Unsupported Python version: Python 2.7.18. Expected: Python 3.7.5 or later.
```

## 可能原因

当前系统的Python版本过旧。

## 解决方法

需按照报错提示更新Python版本。
