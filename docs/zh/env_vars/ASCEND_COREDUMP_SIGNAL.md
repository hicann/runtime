# ASCEND\_COREDUMP\_SIGNAL

## 功能描述

设置trace是否注册用于记录异常堆栈的信号处理函数。

取值如下：

- `none`：trace不注册表1所列信号的处理函数。
- 非`none`的其他值：trace注册表1所列信号的处理函数。

trace默认注册表1所列信号的处理函数。进程触发这些信号时，trace会将异常堆栈信息记录在`stackcore_tracer_*.txt`文件中。

**表1**  信号集

| 信号 | 信号值 |
| --- | --- |
| SIGINT | 2 |
| SIGQUIT | 3 |
| SIGILL | 4 |
| SIGTRAP | 5 |
| SIGABRT | 6 |
| SIGBUS | 7 |
| SIGFPE | 8 |
| SIGSEGV | 11 |
| SIGTERM | 15 |
| SIGXCPU | 24 |
| SIGXFSZ | 25 |
| SIGSYS | 31 |
| SIGRTMIN+1 | 35 |

如果业务自身也需要注册表1所列信号的处理函数（例如使用JVM信号捕获），可能与trace的信号处理函数冲突。此时，需要通过该环境变量关闭trace的信号处理函数注册。冲突场景的日志示例如下：

关闭trace的信号处理函数注册后，如果业务触发core dump，trace不会生成异常堆栈文件，需要借助其他方式定位问题。

## 配置示例

```sh
export ASCEND_COREDUMP_SIGNAL=none
```

## 使用约束

无

## 支持的型号

全量芯片支持
