# ASCEND\_AICORE\_SYNC\_MATCH\_CHECK

## 功能描述

控制是否开启AI Core任务同步匹配检测，可用于定位算子中的同步指令不匹配问题，包括同一AI Core内不同流水线之间的set/wait指令不匹配，以及不同AI Core之间的核间同步不匹配。

取值为：

- 0：关闭。不开启AI Core任务同步匹配检测。
- 1：开启。Runtime在运行AI Core任务时进行AI Core任务同步匹配检测；检测到同步不匹配时，在错误信息中输出不匹配的流水线或核间不同步等错误信息。
- 其他值：与配置为0时相同。

>**须知：**
>
>- 该环境变量默认关闭。未配置或配置为空时，与配置为0时相同。
>- 该功能用于算子调试，开启后可能影响算子的执行性能。

## 配置示例

```bash
export ASCEND_AICORE_SYNC_MATCH_CHECK=1
```

## 使用约束

- 该环境变量不支持动态修改。调用任意Runtime接口前需完成配置，Runtime初始化后修改不生效。
- 建议仅在定位AI Core任务同步不匹配问题时开启，问题定位完成后及时关闭。
