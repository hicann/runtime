# EH0001 Invalid\_Argument

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: parameter value, parameter name, error cause.

```text
Value %s for %s is invalid. Reason: %s.
```

Error example:

```text
Value 0 for size is invalid. Reason: size must be greater than zero.
```

## Solution

Please adjust the parameter value according to the prompts in the error message.
