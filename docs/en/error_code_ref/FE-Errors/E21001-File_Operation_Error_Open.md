# E21001 File\_Operation\_Error\_Open

## Symptom

The following is error format. The placeholder %s indicates the file name.

```text
Failed to open file %s.
```

Error example:

```text
Failed to open file /home/module/fusion_switch.json.
```

## Possible Cause

1. The file does not exist.
2. Insufficient file permissions.
3. Package installation error.

## Solution

1. Configure the file path correctly.
2. Configure the file permissions correctly.
3. Reinstall the package.
