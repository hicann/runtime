# E40002 Environment\_Error\_Incorrect\_Python\_Version

## Symptom

The following is error format. The placeholder %s indicates the version.

```text
Unsupported Python version: %s. Expected: %s or later.
```

Error example:

```text
Unsupported Python version: Python 2.7.18. Expected: Python 3.7.5 or later.
```

## Possible Cause

The current Python version is too old for the system.

## Solution

Update Python to a supported version.
