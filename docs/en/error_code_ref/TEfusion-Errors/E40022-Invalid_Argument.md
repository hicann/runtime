# E40022 Invalid\_Argument

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: parameter value, parameter name, expected value.

```text
Value %s for parameter %s is invalid. The value must be %s.
```

Error example:

```text
Value true for parameter opDebugLevel is invalid. The value must be 0 or 1.
```

## Solution

Please configure the correct value as prompted in the error message.
