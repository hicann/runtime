# EK0002 Invalid\_Argument\_API\_Call\_Sequence

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: API name, API name.

```text
Please call the APIs in the following order: call %s first, then %s.
```

Error example:

```text
Please call the APIs in the following order: call aclprofInit first, then aclprofStart.
```

## Solution

Please call the APIs in the correct order as prompted in the error message.
