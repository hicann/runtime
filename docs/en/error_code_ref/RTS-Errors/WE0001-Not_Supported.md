# WE0001 Not\_Supported

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: task, error cause.

```text
Failed to %s because %s is not supported.
```

Error example:

```text
Failed to set the Inf/NaN mode because only the saturation mode can be set，the Inf/NaN mode is not supported.
```

## Solution

Please adjust the code logic according to the prompts in the error message.
