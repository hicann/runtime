# profiling

本目录聚焦Profiling的配置创建、msproftx标记以及模型订阅能力。

## 产物解读

Profiling产物路径、解析命令和字段含义请参见[Profiling产物解读](./profiling_artifact_analysis.md)。

## 样例列表

- [0_create_config](./0_create_config/README.md)：演示Profiling配置创建、开启和停止采集。
- [1_msproftx](./1_msproftx/README.md)：演示msproftx事件标记、嵌套范围和非嵌套范围标记。
- [2_subscribe_model](./2_subscribe_model/README.md)：演示Profiling模型订阅和性能数据获取。
- [3_mstx_with_domain](./3_mstx_with_domain/README.md)：演示mstx接口在默认domain与自定义domain中打点的使用方式。
