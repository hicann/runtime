# notify

This directory focuses on Notify, IPC Notify, and CntNotify synchronization capabilities.

## Sample List

- [0_ipc_notify_withpid](./0_ipc_notify_withpid/README_en.md): Demonstrates IPC Notify sharing with process whitelist validation enabled.
- [1_ipc_notify_withoutpid](./1_ipc_notify_withoutpid/README_en.md): Demonstrates IPC Notify sharing with process whitelist validation disabled.
- [2_reusable_stream_handoff](./2_reusable_stream_handoff/README_en.md): Demonstrates data rotation between producer and consumer Streams on one Device with batch Notify reset.
