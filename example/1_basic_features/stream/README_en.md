# stream

This directory focuses on Stream creation, synchronization, multi-stream concurrency, and failure mode control capabilities.

## Sample List

- [0_simple_stream](./0_simple_stream/README_en.md): Demonstrates Stream creation, usage, and release.
- [1_stream_with_failure_mode](./1_stream_with_failure_mode/README_en.md): Demonstrates Stream failure mode control.
- [2_multi_stream](./2_multi_stream/README_en.md): Demonstrates multi-Stream coordinated execution and synchronization.
- [3_stream_config_query](./3_stream_config_query/README_en.md): Demonstrates configured Stream creation and attribute queries.
- [4_stream_resource_budget](./4_stream_resource_budget/README_en.md): Demonstrates Stream resource budget configuration, thread binding, and restoration.
