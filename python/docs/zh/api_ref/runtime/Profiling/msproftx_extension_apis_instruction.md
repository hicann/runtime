# 总体说明

- **调用接口要求**：msproftx功能相关接口须在[acl.prof.start](function-start.md)接口与[acl.prof.stop](function-stop.md)接口之间调用。其中配对使用的接口有：[acl.prof.create\_stamp](function-create_stamp.md)/[acl.prof.destroy\_stamp](function-destroy_stamp.md)、[acl.prof.push](function-push.md)/[acl.prof.pop](function-pop.md)、[acl.prof.range\_start](function-range_start.md)/[acl.prof.range\_stop](function-range_stop.md)。
- **接口调用顺序**：[acl.prof.start](function-start.md)接口\(指定Device 0和Device 1\)--\>[acl.prof.create\_stamp](function-create_stamp.md)接口--\>[acl.prof.set\_stamp\_trace\_message](function-set_stamp_trace_message.md)接口--\>[acl.prof.mark](function-mark.md)接口--\>\([acl.prof.push](function-push.md)接口--\>[acl.prof.pop](function-pop.md)接口\)或\([acl.prof.range\_start](function-range_start.md)接口--\>[acl.prof.range\_stop](function-range_stop.md)接口\)--\>[acl.prof.destroy\_stamp](function-destroy_stamp.md)接口--\>[acl.prof.stop](function-stop.md)接口\(与[acl.prof.start](function-start.md)接口的aclprofConfig数据保持一致\)。
