# aclCANNPackageName

| 数据格式 | 说明 |
| --- | --- |
| ACL_PKG_NAME_CANN | 表示查询CANN的版本号。 |
| ACL_PKG_NAME_RUNTIME | 表示查询CANN中Runtime的版本号。 |
| ACL_PKG_NAME_COMPILER | 表示查询CANN中Compiler的版本号。 |
| ACL_PKG_NAME_HCCL | 表示查询CANN中HCCL的版本号。 |
| ACL_PKG_NAME_TOOLKIT | 表示查询CANN中Toolkit的版本号。 |
| ACL_PKG_NAME_OPP | 表示查询CANN中Opp的版本号。 |
| ACL_PKG_NAME_OPP_KERNEL | 表示查询CANN中kernels的版本号。 |
| ACL_PKG_NAME_DRIVER | 表示查询Driver的版本号。 |
