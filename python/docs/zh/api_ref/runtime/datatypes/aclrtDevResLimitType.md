# aclrtDevResLimitType

| 数据格式 | 说明 |
| --- | --- |
| ACL_RT_DEV_RES_CUBE_CORE = 0 | AI Core或Cube Core |
| ACL_RT_DEV_RES_VECTOR_CORE=1 | Vector Core |

关于Core的定义及详细说明，请参见[aclrtDevAttr](aclrtDevAttr.md)。
