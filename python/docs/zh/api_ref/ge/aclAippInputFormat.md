# aclAippInputFormat

| Aipp输入图像格式 | 说明 |
| --- | --- |
| ACL_YUV420SP_U8 = 1 | 静态AIPP和动态AIPP都支持。 |
| ACL_XRGB8888_U8 = 2 | 静态AIPP和动态AIPP都支持，静态AIPP支持，动态AIPP不支持。 |
| ACL_RGB888_U8 = 3 | 静态AIPP和动态AIPP都支持。 |
| ACL_YUV400_U8 = 4 | 静态AIPP和动态AIPP都支持，静态AIPP支持，动态AIPP不支持。 |
| ACL_NC1HWC0DI_FP16 = 5 | 暂不支持 |
| ACL_NC1HWC0DI_S8 = 6 | 暂不支持 |
| ACL_ARGB8888_U8 = 7 | 静态AIPP和动态AIPP都支持暂不支持。 |
| ACL_YUYV_U8 = 8 | 静态AIPP和动态AIPP都支持暂不支持。 |
| ACL_YUV422SP_U8 = 9 | 静态AIPP和动态AIPP都支持暂不支持。 |
| ACL_AYUV444_U8 = 10 | 静态AIPP和动态AIPP都支持暂不支持。 |
| ACL_RAW10 = 11 | 静态AIPP和动态AIPP都支持暂不支持。 |
| ACL_RAW12 = 12 | 静态AIPP和动态AIPP都支持暂不支持。 |
| ACL_RAW16 = 13 | 静态AIPP和动态AIPP都支持暂不支持。 |
| ACL_RAW24 = 14 | 暂不支持。 |
| ACL_AIPP_RESERVED = 0xffff | 暂不支持。 |
