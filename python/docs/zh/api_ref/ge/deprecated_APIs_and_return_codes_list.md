# 废弃接口/返回码列表

## 接口

- [acl.op.execute](function-execute-0.md)接口

 此接口后续版本会废弃，请使用[acl.op.execute\_v2](function-execute_v2-1.md)接口。

- [acl.get\_tensor\_desc\_dim](function-get_tensor_desc_dim.md)接口

 此接口后续版本会废弃，请使用[acl.get\_tensor\_desc\_dim\_v2](function-get_tensor_desc_dim_v2.md)接口。

- [acl.set\_tensor\_storage\_shape](function-set_tensor_storage_shape.md)接口

 此接口后续版本会废弃，请使用[acl.set\_tensor\_shape](function-set_tensor_shape.md)接口。

- [acl.set\_tensor\_storage\_format](function-set_tensor_storage_format.md)接口

 此接口后续版本会废弃，请使用[acl.set\_tensor\_format](function-set_tensor_format.md)接口。

## 返回码

- [ACL\_ERROR\_NONE](aclError.md)

 此返回码后续版本会废弃，请使用[ACL\_SUCCESS](aclError.md)返回码。

- [ACL\_ERROR\_NOT\_STATIC\_AIPP](aclError.md)

 此返回码后续版本会废弃，请使用[ACL\_ERROR\_GE\_AIPP\_NOT\_EXIST](aclError.md)返回码。

- [ACL\_ERROR\_STREAM\_NOT\_SUBSCRIBE](aclError.md)

 此返回码后续版本会废弃，请使用[ACL\_ERROR\_RT\_STREAM\_NO\_CB\_REG](aclError.md)返回码。

- [ACL\_ERROR\_THREAD\_NOT\_SUBSCRIBE](aclError.md)

 此返回码后续版本会废弃，请使用[ACL\_ERROR\_RT\_THREAD\_SUBSCRIBE](aclError.md)返回码。

- [ACL\_ERROR\_WAIT\_CALLBACK\_TIMEOUT](aclError.md)

 此返回码后续版本会废弃，请使用[ACL\_ERROR\_RT\_REPORT\_TIMEOUT](aclError.md)返回码。

- [ACL\_ERROR\_INVALID\_DEVICE](aclError.md)

 此返回码后续版本会废弃，请使用[ACL\_ERROR\_RT\_INVALID\_DEVICEID](aclError.md)返回码。

- [ACL\_ERROR\_GROUP\_NOT\_SET](aclError.md)

 此返回码后续版本会废弃，请使用[ACL\_ERROR\_RT\_GROUP\_NOT\_SET](aclError.md)返回码。

- [ACL\_ERROR\_GROUP\_NOT\_CREATE](aclError.md)

 此返回码后续版本会废弃，请使用[ACL\_ERROR\_RT\_GROUP\_NOT\_CREATE](aclError.md)返回码。
